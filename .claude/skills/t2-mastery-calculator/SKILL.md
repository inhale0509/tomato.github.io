# T2 — 체화 정도 계산 도구

T2는 스크립트 하나가 "내 것"이 됐는지를 0/25/50/75/100% 중 하나로 판정한다. T1이 매기는 "채점 등급"과는 완전히 다른 지표다 — 채점 등급이 낮아도(예: Intermediate Mid) 체화 정도는 100%일 수 있고, 그 반대도 가능하다. T2는 절대 등급을 매기지 않는다.

## 입력 받는 법

필요한 것 세 가지:
1. **최초 스크립트**와 **수정된 스크립트** — 대시보드 "복습 정보 복사" 버튼을 누르면 이 둘과 주요 표현 5개가 한 번에 복사된다. 사용자가 그걸 그대로 붙여넣으면 된다.
2. **주요 표현 5개** — 위와 같이 "복습 정보 복사"에 포함되어 있다.
3. **복습 시점의 전사 결과** — 오늘 다시 소리 내어 말한 것을 전사한 텍스트. 이건 매번 새로 생기는 것이라 사용자가 직접 붙여넣어야 한다.

셋 중 하나라도 없으면 계산하지 말고 되묻는다. 특히 "복습 시점의 전사 결과"가 없으면(스크립트 정보만 왔으면) "오늘 다시 말해본 내용을 전사해서 알려주세요"라고 요청한다 — 이게 없으면 애초에 체화 정도를 판단할 근거가 없다.

(선택) 복습 시 T1을 다시 돌렸다면 그 채점 결과도 참고 자료로 쓸 수 있다 — 있으면 활용하고, 없어도 무방하다.

## 계산 근거 — 세 가지를 통합 판단 (기계적 평균 아님)

**① 최초 대비 수정량** — 최초 스크립트와 수정된 스크립트를 비교한다. 고친 게 적었다면(어휘·문법이 이미 좋았다면) 그만큼 처음부터 자기 실력에 가까운 스크립트였다는 뜻이고, 많이 고쳤다면 아직 스크립트 자체가 자기 것이 아니었다는 뜻이다. 이건 체화 정도의 "출발점" 역할을 한다 — 수정량이 적을수록 체화 정도가 더 높게 나올 여지가 있다.

**② 복습 시 막힘없이 말한 정도** — 복습 전사 결과에서 필러(um, uh)·긴 멈춤·문장이 끊기는 지점이 얼마나 있는지, 그리고 원본/수정 스크립트와 내용·구조가 얼마나 일치하는지를 본다. 토씨 하나까지 같을 필요는 없다 — 같은 내용을 자기 말로 자연스럽게 재현했다면 오히려 좋은 신호다. 반대로 원본 내용의 상당 부분을 아예 빼먹었거나 완전히 다른 이야기를 했다면 낮은 신호다.

**③ 표현 활용도** — 선택된 주요 표현 5개 중 몇 개를 이번 복습 답변에서 실제로 썼는지 센다(정확히 토씨가 같을 필요 없이, 의미·형태가 살아있으면 사용한 것으로 인정). 5개 중 몇 개를 썼는지가 체화 정도에 직접적으로 반영된다.

## 판정 가이드 (참고 기준점 — 절대 공식 아님)

| 체화 정도 | 대략 이런 경우 |
|---|---|
| 100% | 최초 대비 수정이 거의 없었고, 복습 때도 막힘없이 원본 내용을 자기 말로 재현했으며, 주요 표현 5개를 거의 다(4~5개) 사용 |
| 75% | 수정이 어느 정도 있었지만 구조는 유지됐고, 복습 때 대체로 자연스러웠으며(약간의 필러/멈춤 정도), 표현을 3~4개 사용 |
| 50% | 수정이 꽤 많았고, 복습 때 군데군데 막히거나 원본 내용 일부를 빠뜨렸으며, 표현을 2~3개 사용 |
| 25% | 수정이 많아서 거의 다시 쓴 수준이었고, 복습 때 많이 막히거나 원본 내용을 잘 기억하지 못했으며, 표현을 0~1개 사용 |
| 0% | 복습 전사가 원본과 거의 무관하거나, 사실상 다른 내용을 말했거나, 거의 아무것도 기억하지 못한 경우 |

세 요소가 서로 다른 방향을 가리키면(예: 수정은 적었지만 이번엔 많이 막혔다) 기계적으로 평균 내지 말고, 무엇이 더 "지금 이 순간의 체화 상태"를 잘 나타내는지 판단해서 하나를 고른다 — 판단 근거를 출력에 반드시 한두 문장으로 남긴다.

## 이어서 진행하기 — 표현 테스트→재학습→평균 집계까지 한 번에 (T3~T5)

체화 정도 판정을 낸 직후, 입력에 "주요 표현 N개" 목록이 포함돼 있었다면 **사용자가 다시 요청하지 않아도** 자동으로 이어서 진행한다 — 왕복을 줄이는 게 목적이므로 여기서 멈추고 기다리지 않는다. 표현 목록이 아예 없는 입력(스크립트 정보만 온 경우)이면 이 확장 흐름 전체를 생략하고 체화 정도만 낸다 — 하위 호환이다.

1. **표현 테스트 (T3 기준)**: 표현들을 번호를 매겨 한국어 뜻으로 제시하고, 사용자의 영어 답을 **의미 보존 여부**로 채점한다(토씨 하나까지 일치할 필요 없음 — paraphrase 허용, 원래 의도에서 크게 벗어나야만 오답).
2. **재학습 루프 (T4 기준)**: 오답이 나온 표현만 다시 한국어로 제시 → 재답변 → 재채점, 정답이 되거나 사용자가 그만두겠다고 할 때까지 반복.
3. **표현별 최종 masteryPct 산정**(총 시도 횟수 기준, T3/T4가 공유하는 잠정 규칙): 1회 만에 정답=100, 2회=75, 3회=50, 4회 이상=25, 끝내 못 맞추고 포기=0.
4. **주제 평균 집계 (T5 기준)**: 표현들의 최종 masteryPct를 산술평균 → 가장 가까운 0/25/50/75/100로 반올림(정확히 중간값이면 올림).

단독으로 표현만 다시 테스트하고 싶을 때(스크립트 재채점 없이)는 T3를 직접 불러도 된다 — 이 확장 흐름은 그 로직을 복습 세션 안에 그대로 이어붙인 것뿐이다.

## 출력 형식

1. 짧은 판단 근거 (①②③ 각각에 대해 한 줄씩, 무엇을 관찰했는지)
2. **체화 정도: NN%** (한 줄, 굵게)
3. 표현 테스트를 진행했다면 표현별 정답/오답·최종 결과 요약
4. 대시보드로 보낼 JSON — 표현 테스트를 안 했으면 `expressionResults`/`avgExpressionMastery` 없이 처음 두 필드만, 진행했으면 전부 포함:

```json
{
  "topic": "카페/커피전문점 가기",
  "masteryPct": 75,
  "note": "표현 5개 중 4개 사용, 필러 약간 있었지만 구조는 원본과 거의 동일",
  "expressionResults": [
    { "text": "my go-to spot", "finalCorrect": true, "totalAttempts": 1, "masteryPct": 100 },
    { "text": "that sort of thing", "finalCorrect": true, "totalAttempts": 2, "masteryPct": 75 }
  ],
  "avgExpressionMastery": 100
}
```

- `topic`은 사용자가 준 주제명 그대로.
- `masteryPct`(스크립트 전체)와 `avgExpressionMastery`(표현 평균)는 각각 반드시 0, 25, 50, 75, 100 중 하나(숫자, 문자열 아님) — 서로 다른 지표이니 헷갈리지 않는다.
- `note`는 한 문장으로, 왜 이 수치가 나왔는지 요약.
- `expressionResults[].text`는 표현 원문 그대로(대시보드 표현 DB의 이름과 매칭하는 키).

JSON을 준 뒤 "위 JSON을 대시보드 2-2 화면의 '복습 결과 가져오기'에 붙여넣으면 체화 정도부터 표현 평균까지 한 번에 갱신돼요"라고 한 줄로 안내한다.
