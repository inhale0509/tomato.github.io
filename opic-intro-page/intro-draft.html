OPIC 이란

컴퓨터 앞에서 치르는 영어 말하기 시험이다. 배경설문으로 주제를 고르면 그 주제로 즉석 답변을 녹음하고, 그 답변으로 등급을 받는다.

☺ AVA
NL NM NH IL IM IH AL

일곱 단계 중 IH~AL이 목표 범위다.

문제 정의

청년들의 자격증 준비 부담

많은 20대 청년은 자격증을 준비해야 하지만, 시간과 비용을 넉넉히 들이기 어려워 온라인 강의나 독학을 택한다. 그러나 자기 관리와 객관적인 피드백의 부재 때문에 안정적인 합격이 어렵다고 느끼며, 큰 심리적 부담을 갖는다.

OPIC의 특성

설문 결과에 따라 시험이 개인화되기 때문에, 응시자 스스로 자료를 예측하고 스크립트·표현을 찾아야 해서 독학이 더욱 어렵다.

형태

서비스는 Claude Artifact와 Claude Code, 두 가지 공간을 함께 쓴다.

웹 브라우저 — 학습 대시보드

지속적 동기부여와 초심 유지, 학습 스케줄 관리가 이루어지는 공간이다.

Claude Code — 습득

질문 pool 제공, 객관적인 스크립트 피드백, 에빙하우스 기반 복습이 이루어지는 공간이다.

사용 흐름

처음 사용할 때 프로필 설정→배경설문→스케줄 자동생성→시작 문구
다음부터는 시작 화면→대시보드→전체 조회→내보내기·가져오기
새로 배울 때 전사 입력→채점·피드백→표현 선택→체화 계산→Notion 반영
복습할 때 복습 확인→채점·피드백→체화 재계산→표현 채점→오답 재학습→Notion 반영

화면 스크린샷은 준비 중이다 — 자리만 먼저 잡아둔다.

개발 이야기

처음 설계

화면에서 곧바로 Claude를 부르고, 결과까지 자동으로 저장하려 했다

부딪힌 문제

브라우저 코드 안에서는 인증 정보가 그대로 드러난다

정리한 방향

판단은 Claude와의 대화로, 저장은 브라우저·Notion으로 나누고, 인증키는 Render 백엔드 서버 안에만 두었다

NEW!

업데이트 예정

Claude와 나눈 대화 내용을 API로 직접 불러올 수 있다는 걸 확인하고, 이 부분을 반영하는 업데이트를 진행하고 있다. T0~T7 도구를 순서대로 만들고, Render에 백엔드 서버를 올려 API 키를 서버 쪽에만 두는 구조로 정리하는 중이다.
