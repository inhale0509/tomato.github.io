# OPIC 어시스턴트 — 소개 페이지 (Phase 2 리뉴얼)

> 이 폴더는 OPIC 어시스턴트 제품의 신규 소개(랜딩) 페이지 작업 전용 스코프다. 루트 `CLAUDE.md`의 스코프 원칙을 그대로 따르되, "지정된 스코프"는 이 폴더 하위 파일들이다. T0~T7 스킬, `index.html`(제품 본체), `backend/`는 이 작업에서 건드리지 않는다.

## 배경

- OPIC 어시스턴트는 T0~T7 도구를 API로 연결해 Claude 대화 내용을 자동으로 불러오는 방향으로 업데이트 중이다 (T0~T7 제작 + Render에 백엔드를 API 키와 함께 배포).
- 시제품이 거의 완성되어, 이번에 **Phase 2 업데이트 내용을 반영한 새 소개 페이지**를 만든다.
- 기존 소개 아티팩트: `OPIC 어시스턴트 — 소개` (https://claude.ai/code/artifact/f0351f54-d2ff-4257-985c-6ff11ae0763b, 2026-07-28 업데이트).
  - **내용(카피, 정보 구조, 담긴 메시지)은 참고**하되, **디자인·레이아웃은 완전히 새로 만든다** — 기존 것은 디자인 정렬이 맞지 않는다는 판단.
  - 기존 아티팩트 구조 요약: 상단 nav → hero(제품명/한 줄 소개/통계 3개) → OPIC 시험 소개 → 스크립트/표현 정리라는 두 축 → AI 활용 전/후 비교 → 아키텍처(웹 대시보드 vs Claude) → 자동화 기능 목록 → 에빙하우스 복습 곡선 차트 → 개발 중 겪은 문제(설계 변경 스토리) → 화면 흐름 / 대화 흐름 다이어그램 → 인용구 → 푸터.

## 이번 작업의 목표

1. Phase 2 업데이트(백엔드 API 연동, Render 배포)를 반영한 새 소개 페이지 제작.
2. 페이지 안에 **제품 체험 링크**를 포함— 실제 제품(`index.html`)으로 바로 연결되는 CTA.
   - 저장소가 `inhale0509/tomato.github.io`이므로 GitHub Pages 배포 시 제품 URL은 `https://inhale0509.github.io/` 가 된다(루트 `index.html`이 제품 대시보드).
   - 배포 상태(백엔드 Render URL, GitHub Pages 활성화 여부)는 작업 시점에 다시 확인할 것 — 이 문서에 적힌 값은 추정/스냅샷이므로 그대로 믿지 말고 확인 후 사용.
3. 디자인·배치는 기존 소개 아티팩트와 완전히 다르게 새로 설계.

## 작업 순서

1. 먼저 **아티팩트(Artifact)로 렌더링하며 디자인 반복** — claude.ai에서 바로 보고 피드백받으며 조정.
2. 디자인이 확정되면 **최종 HTML 파일로 이 폴더에 저장**.
3. 그 HTML을 **GitHub Pages에 배포** (저장소 루트 또는 별도 경로 — 배치 방식은 작업 시점에 사용자와 확인).

## 제약

- 이 폴더 밖(T0~T7 스킬, `index.html`, `backend/`)은 소개 페이지 작업 중 발견한 이슈라도 그 자리에서 고치지 않는다 — 루트 `CLAUDE.md` 3항 원칙대로 한 줄 안내 또는 `spawn_task`로만 남긴다.
- 겸사겸사 리팩터링 금지 — 소개 페이지 스코프에만 집중한다.
